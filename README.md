# quasar_resaas

**The frontend of RESAAS** - a Vue 3 + Quasar library that turns a
[django_resaas](https://github.com/metanochava/django_resaas) API into working screens: `s-*`
components, AutoCrud lists, schema-driven forms, Pinia stores, layouts, routes, sign-in with
the tenant context, permissions and action dialogs.
