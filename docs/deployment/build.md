# Build e Publicação

## Antes do build

Verificar:

-   endpoint da API;
-   variáveis de ambiente;
-   rotas;
-   assets;
-   imports;
-   versão do pacote.

## Build

Executar o comando de build definido pelo projeto Quasar/package.json.

## Produção

Confirmar que o servidor web entrega corretamente os assets da SPA e que
o fallback de rotas aponta para o `index.html` quando necessário.
